Petit lexique

Les mots utilisés plus bas, sans jargon.

mAP (précision moyenne)
À quel point les cadres proposés tombent juste, toutes confiances confondues.
Rappel (sensibilité)
Part des anomalies réelles que le modèle retrouve : ce qu’il « ne laisse pas passer ».
Précision
Part des propositions du modèle qui sont justes. Pour un détecteur de cadres, elle remplace la spécificité, qui n’a pas de sens sans « vrais négatifs ».
Seuil de confiance
Niveau minimal de confiance au-dessous duquel une détection n’est pas affichée.
IoU
Recouvrement entre le cadre proposé et le cadre de référence.

Limites connues

  • Entraîné sur un jeu public dont les appareils et les populations diffèrent peut-être de ceux des cabinets de Toliara.
  • Performance non évaluée sur des images du contexte local.
  • Ne détecte que 4 types d’anomalies : pas les parodontopathies, fractures, kystes, tumeurs, restaurations…
  • Sensible à la qualité de l’image (flou, mauvais positionnement, artefacts métalliques).
  • Les dents incluses partiellement visibles peuvent être mal numérotées.
  • Non certifié dispositif médical.
  • Ne remplace pas un examen clinique ni d’autres examens d’imagerie.

Comment ces mesures sont obtenues

  1. Un jeu de test séparéDes images jamais vues par le modèle pendant l’entraînement.
  2. Comparaison aux annotations de référenceChaque cadre proposé est comparé à celui des annotations de référence de DENTEX.
  3. Calcul par classeLes mesures sont calculées séparément pour chaque classe, puis toutes classes confondues.
